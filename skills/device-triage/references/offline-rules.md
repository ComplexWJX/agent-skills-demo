# 演示用离线判断口径

- 这是一组可修改的业务规则，不代表通信协议的通用标准。
- 业务心跳年龄超过 expected_heartbeat_seconds 的 3 倍，标记为“业务心跳超时”。
- transport_connected=true 仅表示服务端仍保留连接状态，不能单独证明设备业务可用。
- ping-sent 仅表示发送事件；发送完成不能证明客户端已收到或已返回 pong。
- 没有客户端回应记录时，不能声称收到了 pong。
- 心跳超时与连接仍在同时出现，可排查网络黑洞、客户端业务线程阻塞、
  心跳调度异常或连接状态未及时清理；单凭这些字段不能区分根因。
- 所有结论必须按 observed_at 判断。source=demo-fixture 表示固定演示快照，
  必须说明这是测试数据，不能描述为当前真实设备状态。

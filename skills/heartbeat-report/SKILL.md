# 心跳质量报告

1. 确认设备编号，未提供时先询问。
2. 调用 summarize_heartbeat_intervals(device_id)，由程序完成数值计算。
3. 若设备不存在或无样本，如实说明，不得自行补全样本。
4. 输出观测时间、数据来源、样本数、平均间隔、最大间隔、阈值、超阈值数量与占比。
5. 占比使用百分数展示；统计工具已返回比例，例如 0.5 显示为 50%。
6. “超阈值”指严格大于预期心跳间隔两倍；不能将样本占比解释为设备离线时长比例。
7. source=demo-fixture 表示固定测试数据，报告必须明确标注。
